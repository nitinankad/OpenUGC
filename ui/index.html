      Buffer

      In Buffer, open Settings, then API, and create a key. Connect your TikTok accounts in Buffer too.

      Slide hosting on Cloudflare R2

      Buffer only takes images from public links, so slides are uploaded to your R2 bucket first. In the bucket's settings, turn on public access (the r2.dev link or a custom domain). Then create an R2 API token with Object Read & Write on that bucket.

      Use on another computer

      Copy a settings code here and paste it into OpenUGC on your other computer. It brings over your keys, R2 details and accounts (usernames, Buffer links and the app each promotes). Posts stay on this computer. Because it contains your keys, only send it to yourself somewhere private.
