                Slide hosting on Cloudflare R2

                Send to phone uploads each post's slides and a small page to your R2 bucket, so your phone can open them from a link. In the bucket's settings, turn on public access (the r2.dev link or a custom domain). Then create an R2 API token with Object Read & Write on that bucket.

                To clear out old posts automatically, add a lifecycle rule in the bucket's settings that deletes objects with the prefix phone/ after a few weeks.

                Analytics
